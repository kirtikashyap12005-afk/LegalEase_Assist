# LegalEase Assist

LegalEase Assist is a MERN-based legal guidance platform designed to help users understand their legal rights through a simple and user-friendly interface.

## Features

- Voice-assisted legal guidance
- Guided legal questionnaires
- Rights information based on user responses
- Official government resources and helplines
- Evidence Vault for storing case-related documents
- Emergency contact section
- Responsive React + Vite frontend
- Node.js + Express backend
- MongoDB database integration

## Tech Stack

- React
- Vite
- Node.js
- Express.js
- MongoDB
- CSS

## Installation

```bash
npm install
npm run dev
```

## Backend

```bash
cd Server
npm install
npm start
```
